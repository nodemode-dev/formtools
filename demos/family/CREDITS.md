# Demo credits

Nothing in this demo is third-party media. Every file in the recording was made by formtools' own demo generator (`backend/app/tools/demos/family.py`): the formvis project and its preview, the PDF, the database, the font (Demo Pixel, drawn from the generator's own pixel glyphs with fontTools), the archive, the data, the code and the checksums. "Shelf Supply Co.", the orders, items and prices are invented.

`assets/recording.js` holds the engine's answers for that folder, recorded by `scripts/demo-record.py`. The script, stylesheet and fonts the page loads are the shared ones in `demo/assets/`; their third-party contents are listed in `demo/CREDITS.md` and `NOTICE.md`.

The app opens the same demo from Home > Demos, Help > Demos and the `demo-family` command, with the same generator, so this note covers it too.
