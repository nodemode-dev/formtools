# OS baseline players: QuickTime Player (macOS) and Media Player (Windows 11)

Researched 2026-11-03. Brief baseline only.

## QuickTime Player

Apple's bundled macOS player. Per Apple's guide: open and play files, resize, show subtitles or captions, choose soundtrack, view file info; trim, split, rearrange, rotate, flip clips; record screen (full or selection), movie from camera or a connected iPhone/iPad screen, and audio; build a movie from an image sequence; export and share. Speed control and PiP are not in the fetched page (unverified). Proprietary, macOS only.

formtools note: Baseline expectation: open, trim, record, export with zero setup.

## Media Player (new, Windows 11)

Replaced Groove Music; rolled out to Insiders 2021-11. Per Microsoft's launch post: music library from Music and Video folders with configurable locations, playlists (Groove playlists migrate), album art and artist imagery in playback, full-screen and mini player, dedicated video view, keyboard and accessibility work, known issues with network playback and metadata editing. Legacy Windows Media Player remains under Windows Tools. Equalizer, CD, casting not confirmed from fetched pages (unverified). Proprietary, Windows only. The Windows N Media Feature Pack exists for editions without media components (title seen in search results, not fetched).

formtools note: Library-first design with mini player is the modern baseline for audio.
