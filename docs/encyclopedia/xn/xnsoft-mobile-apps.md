## Details verified from stores
- XnConvert Android: stretch/fit-in/fit-over resize, bilinear or Lanczos with sharpening, adjustable compression, keeps EXIF and file date, reusable templates, originals untouched. Updated 2025-08-12, contains ads; Pro (no ads, no template or batch limits) is paid, price not shown.
- XnConvert Mac: v1.118.0, free, no IAP, opens 500+ and writes 80+ formats, saved action pipelines.
- XnView Photo Fx Editor (iOS): v2.39, last updated 2019-05-21, free, no ads. Tools: crop/rotate/straighten/mirror; vintage, frame, texture, layer, bokeh, light-leak effects; gamma/brightness/contrast/hue/saturation/exposure/colour balance; B&W, dither, sepia; sketch, charcoal, halftone, pointillize, crystallize; blur, motion blur, tilt shift, glow; symmetry, kaleidoscope, marble, waves; edge, emboss, noise filters. Dormant since 2019 (inferred).
- No app named "XnView Photo" exists on the list. Coleka is a separate collector product, not an image utility.

formtools note: the XnConvert mobile feature set (template-based batch pipeline) is the right minimal mobile scope.
formtools note: PhotoFx's effect categories give a ready taxonomy for a filter picker.
