# GFL SDK (Graphics File Library) and GflAx

## What it is
XnSoft's image library that underlies XnView and NConvert, offered as an SDK (C library) and as GflAx, an ActiveX control for Visual Basic style use.

## Evidence found
The download folder (download.xnview.com/versions/GFL_SDK/) holds 18 files: GflSDK for Windows (setup 2009, zip 2011-01-20), Linux x86 and x86-64, macOS (2011-01-20), plus older Solaris, IRIX, FreeBSD, BeOS builds (2008), GflAx (ActiveX, 2008, source zip 2010-04-26), GflAx binaries 3.0 (2010-10-07), and a VB.NET sample (2010). The parent index shows the folder modified 2026-06-04, though nothing visible in it is newer than 2011.

Status: no active development is evidenced; treat as frozen/legacy (inference).

## Licensing
Not published. Two forum threads show users unable to find commercial terms: a "lite" version was said to cost about 100 EUR, the full price was not stated, and the author asked users to email him. Treat as proprietary, contact required.

formtools note: do not depend on GFL; its licence is opaque and builds are old. Use open decoders (libjpeg-turbo, libwebp, libheif, etc.) instead.
