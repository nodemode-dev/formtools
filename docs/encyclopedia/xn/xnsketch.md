# XnSketch

## What it is
One-click photo to drawing, cartoon or sketch converter. Desktop version 1.20.

## Platforms
Windows 32/64-bit zip, Linux 32/64-bit TGZ, macOS via Mac App Store (v1.20, 2020-12-14, free, macOS 10.12+, 23.6 MB). Desktop download folder last touched 2022-09-29, so effectively dormant. Mobile: iOS and Android apps (Android "Sketch Me!", updated 2025-08-02, contains ads).

## Features
- 18 effects on the desktop page; named there: black strokes, white strokes, pastel, pencil sketch, colour sketch. Store listings add cartoon, stamp, halftone, hatching.
- Effect names as labelled in the vendor's Linux build (v1.18, 2016; the page's 1.20 may differ): Black&White, White&Black, Neon, Dull Pastel, Mono, Sketch B&W, Sketch 1 to Sketch 4, Pencil, Cartoon 1, Cartoon 2, Photocopy, Haltfone 1 and Haltfone 2 (the build's own spelling of halftone), Hope, Copycolor, Cutout, Oil, Print, Hatching. That is 22 labels against the page's "18 effects", so either some labels are variants of one effect or later builds trimmed the list; the count mismatch is unresolved.
- Adjustable edge strength and opacity. Slider labels in the build: edges (amount), opacity, blur, colours, a colour picker, and a map choice (Light charcoal, Dark gray, Light gray); a mask picker with "No Mask" is also present.
- Contrast, brightness, saturation controls; the build also has gamma and exposure sliders.
- Save or share.
UI flow: load a photo, click an effect thumbnail, adjust sliders, save. Presets, formats and licence not stated.
formtools note: edge-detect plus tone mapping plus paper blend covers most of the styles; expose edge strength and opacity as the two main controls.
