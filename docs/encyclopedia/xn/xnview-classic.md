# XnView Classic

## What it is
The original Windows-only image viewer, organizer and converter. The site now labels it "legacy" and recommends XnView MP. Version 2.52.7 is listed; its download folder was modified 2026-09-23, so it is not abandoned, but the forum release thread for 2.52.2 (2025-06-22) is filed under an "Archive" board and the site never states a support policy (not verified).

## Platforms and editions
Windows XP, 7, 10, 11 (per download table). Three editions, each as installer or zip:
- Minimal: English, French, German only; no plugins or add-ons.
- Standard: all languages; plugin jpeg2000; add-ons photomasque, paint, xmp.
- Extended: all plugins and add-ons plus NConvert, shell extension (ShellEx) and Media Detector.
formtools note: a three-tier packaging (core, +common add-ons, +everything) is a good model for optional modules.

## Feature list (from the product page, edition not distinguished)
- Viewing: thumbnails, fullscreen, filmstrip, slideshow with transitions, compare up to 4 images.
- Editing: resize, rotate, crop, lossless JPEG rotate/crop, brightness/contrast/gamma, auto levels/contrast, colour depth and palette changes, filters and effects, paint/annotation.
- Creation: slideshows, contact sheets, video thumbnail galleries, file listings, image strips.
- Batch: convert (shared engine with XnConvert), rename, change timestamps, edit metadata (IPTC; XMP via add-on).
- Other: duplicate finder, advanced search, multimedia player, print module, screen capture, scanner acquisition, Adobe Photoshop-format filter support.
- Formats: over 500 readable, about 70 writable (the site mentions exporting to roughly 70), incl. RAW, HEIC, AVIF, JPEG-XL, DICOM, PDF, multipage and animated (APNG, TIFF, GIF, ICO).
formtools note: this is the reference breadth for a viewer plus utility suite; pick the batch, contact sheet, duplicate finder, and capture items as separate modules.

## Classic versus MP
- Page marks as MP-only: Unicode support, XMP metadata (Classic gets XMP via add-on), Linux/macOS, face detection.
- A 2013 forum thread (MP 0.53 beta era, likely outdated) listed Classic features MP then lacked: red-eye correction, print, file associations, add text/watermark, paint, contact sheet, create web page, multipage file creation, image strip, scanner acquisition, sequence convert, hex view. Users also named side-by-side view, GIF extraction, settings export, tile view for tabs. Community replies said these were "not yet added" rather than removed. Current MP parity not verified here.
- Shortcut/menu-order differences exist (e.g. swap selection width/height uses Tab in Classic, W in MP).
formtools note: shortcut and menu-order parity with the predecessor matters to migrating users; keep keybinding presets.

## Recent changes
2.52.1 updated Libwebp, Ghostscript and JPEG 2000 encoding; 2.52.2 added an NConvert option (-xyb for JPEGli) (forum posts).

## Licensing
Freeware for private, educational and non-profit use; paid per-seat business licence (29.00 EUR single seat, tiered down to 3.90 EUR above 1000). Site states no adware or spyware.
