# Preview keyboard shortcuts

Apple's documented list (macOS 27 guide):

## General
- Save: Command-S
- Next / previous tab: Control-Tab / Control-Shift-Tab
- Full screen: Control-Command-F
- Print: Command-P
- Copy / Cut / Paste: Command-C / X / V
- Scroll a line, next/previous sidebar item or highlight: Down / Up Arrow
- Scroll a screen or move to next/previous image: Page Down / Page Up
- Next / previous document in window: Option-Page Down / Option-Page Up
- Next / previous page: Option-Down / Option-Up Arrow
- Zoom all images to actual size: Option-Command-0
- Zoom to fit: Option-Command-9
- Zoom in / out: Option-Command-Plus / Minus
- Remove background: Shift-Command-K

## 3D
- Zoom to selection or fit scene: Shift-Command-8
- Move / Rotate / Scale tools: Option-W / E / R
- Option-click: select part of group; Option-drag handle: duplicate prim
- Shift-drag gray handle: snap to surface
- Space: play/pause animation; Option-click Play: play once
- Control-Option-drag: zoom to area; Shift-drag: multi-select

## Other (Quick Look/Finder)
- Space: open/close Quick Look; Command-Return: index sheet; Command-Plus/Minus zoom.
- Rotate right: hold Option on Rotate button.

Many other menu shortcuts (e.g. Command-F search) exist but are not in the fetched page.
