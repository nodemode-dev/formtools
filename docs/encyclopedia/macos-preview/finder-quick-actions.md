# Finder Quick Actions and related utilities

## Access
Control-click a file > Quick Actions, or buttons at the bottom of the Finder Preview pane (View > Show Preview). Available actions depend on file type and enabled extensions.

## Built-in actions
- Rotate Left (Option for Right): images and movies; repeat to keep rotating.
- Markup: opens Quick Look with Markup tools (documents, images).
- Trim: movies and audio; yellow handles, Play, Revert, Done; replace or save new file.
- Create PDF: combines selected files in selection order; output named after first selected file; also a Preview pane button.
- Convert Image: format and size selection (HEIC to JPEG or PNG example).
- Remove Background: images; enabled via Customize.
- Customize (More > Customize): enable Finder extensions, add Shortcuts, install Mac App Store actions, Automator workflows as extensions (also Touch Bar, Services menu).

formtools note: mirror each action as a context-menu entry on Windows/Linux file managers and as CLI subcommands.

## Related
