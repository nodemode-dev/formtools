# HASHOUT_LOG · ui/model

## v0.4.0 · 2026-11-03 · 3D viewer (Phase 5 frontend)

- `ModelViewer` (`model-viewer.ts`) builds its DOM once and never touches three.js at import time. `engine.ts` (renderer, scene, controls) and `loaders.ts` are pulled in by dynamic `import()` on the first `open`, so the main bundle stays free of three. Each format loader is a further dynamic import, so a glTF user never downloads the FBX, Collada or USD code.
- One `WebGLRenderer` lives for the life of the window. A new model replaces the old one only after it has loaded (the old frame stays, a delayed pill says Loading); then geometries, materials, textures, skeletons are disposed and the renderer's render lists are left to the next frame. The shared mode materials, the matcap texture, the environment target and the measure and selection helpers are disposed only with the stage.
- Rendering is on demand: OrbitControls `change`, resize, mode, grid, visibility and theme changes request one animation frame; an idle scene draws nothing. Playing an animation runs its own frame loop and stops on pause or close. Damping is off because it would need a loop.
- Size: the canvas is absolutely positioned at 100 percent of `.ft-mv-stage`, which is sized by the grid, so nothing reflows; a `ResizeObserver` sets the drawing buffer; pixel ratio is capped at 2. The panel, the animation bar and the measure readout overlay or sit in their own column and never resize the canvas row.
- Theme: the clear colour is the computed `--canvas-bg`; grid, wireframe, selection and measure colours are read from `--line-2`, `--line-3`, `--text-secondary` and `--accent-color`. Tokens built with `color-mix` compute to `color(srgb ...)`, which three cannot parse, so the colour is rasterised through a 1 px canvas. A `MutationObserver` on the root and body attributes re-reads them when the theme changes.
- Loading: native formats load from `/api/file/raw`; every file referenced from a `.gltf`, `.obj`, `.mtl`, `.fbx` or `.dae` goes through a `LoadingManager` URL modifier to `/api/model/asset`. The loaders are given a fake base (`ftasset://m/`) so the modifier sees exactly the uri written in the file; anything that is not a data or blob URL and not under that base is replaced by a 1 px GIF, so a model cannot make the window fetch from the network. A native failure falls back to `/api/model/view` (GLB); the engine's own sentence is shown when both fail.
- Not included: Draco and KTX2 (Basis) textures, because their decoders are loaded from files by URL and the window ships none (Meshopt is bundled). STL and 3MF open with Z up, because they are Z-up in practice; the toolbar toggle (U) flips it.
- Modes: lit, wireframe, normals, matcap. Each swaps the mesh material for one shared material and restores the file's own materials from a `WeakMap` on return; points and lines keep their own. The matcap is drawn in code (a radial gradient), as is the neutral environment (`RoomEnvironment` through `PMREMGenerator`); no HDR file is downloaded. A headlight and a faint ambient light cover Phong and Lambert materials, which the environment does not light.
- Measure (D): two clicks on the model (a click is under 5 px of movement and 600 ms), a raycast against visible meshes, the line and markers drawn on top; the readout gives the distance and the three axis deltas in world units after the Z-up rotation, with the unit from `/api/model/info` when it states one. Double click recentres the orbit on the point under the cursor.
- Scene panel: nodes (collapsible, an eye toggle per node, click to outline its bounds), materials (swatch, type, use count, each texture slot with its size) and stats (live triangles, vertices, draw calls, GPU textures and geometries, grid cell, plus the file's own numbers from `/api/model/info`). Rows are patched with `patchList` keyed by uuid. Names from the file go through `textContent` only. At most 4000 nodes are listed.
- Keys when the viewer is open and no field has focus: F or Home fit, 1 3 7 9 front, right, top, isometric, M mode, G grid, X axes, U up axis, D measure, P screenshot, H panel, Space plays or pauses when the file has clips, Escape closes the convert menu or leaves measure, otherwise returns false so the viewer can close.
- Screenshot renders once and calls `canvas.toBlob` in the same task (no `preserveDrawingBuffer`), then downloads through an `a` element with a blob URL revoked after 4 s.
- Convert posts `/api/model/convert` and hands the job to `deps.jobs.track`; a toast names the saved file when the job is done.
